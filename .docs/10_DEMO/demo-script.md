## 90-second path

1. **0:00–0:10 — Problem:** show an agent-generated import and impending `npm install`; state that existence is not API compatibility.
2. **0:10–0:23 — Gate:** demonstrate tested Bob `PreToolUse`, or say “wrapper fallback” if the hook is not verified; show no package code executes.
3. **0:23–0:42 — Evidence card:** show exact fixture/artifact/version, rule, source citation, and `BLOCK` because the static symbol is absent.
4. **0:42–1:05 — Repair:** show a revalidated candidate and patch-only plan; never auto-install.
5. **1:05–1:22 — Verify:** apply only after explicit approval, run safe tests, re-run the gate, show hash-chained decision record.
6. **1:22–1:30 — Impact/limit:** show only measured results; state that malicious packages with matching APIs, private registries, and universal shell interception are out of scope.
